  ## What was implemented

  The production implementation contains:

  - General asymmetric z,w update; it never assumes w=z
  - Pure-Triton two-RHS Linv multiplication
  - Hoisted coefficient construction
  - P/Linv-only inverse-factor update
  - Full asymmetric descriptor grid
  - North carry scan
  - West carry scan
  - Final A_w apply with fused vz[:,None] * vw[None,:]
  - Runtime rank with compile-time tile dimensions
  - 64-bit matrix addressing
  - No full-sized A_w intermediate
  - B=64 A_w tiles
  - Tuned P configuration of 16 columns × 32-element chunks

  The optional packed symmetric specialization was not implemented because the asymmetric path, correctness protocol, tuning, and feasible rank ladder consumed the available scope.

  Rejected or deliberately omitted:

  - B=128: measured regression
  - B=32: consistently slower than B=64
  - Explicit float4: not repeated without an AMD-specific reason
  - Four independent prefix chains: not repeated
  - Synchronization-heavy cooperative scan: not repeated
  - Stream overlap: not enabled without evidence
  - Fake matrix/MFMA formulation for vector work: not used
  - Native CUDA/HIP/C++ kernels: prohibited and not used
